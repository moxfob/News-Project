# News-Project

Проект для парсинга и отображения новостей из различных источников.

## 📁 Структура проекта
Основные файлы и папки:
- `news/` — основной каталог проекта
- Файлы: `index.html`, `style.css`, `script.js` — интерфейс сайта
- Python-скрипты — для парсинга новостей

## 🛠 Технологии
- **Frontend**: HTML, CSS, JavaScript
- **Backend/Парсинг**: Python
- **Стилизация**: CSS (основной язык проекта — 41.6%)
